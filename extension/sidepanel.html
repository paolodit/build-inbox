OpenAI Transcript

Optional. Browser speech works without an API key, but OpenAI transcription is usually faster to review and gives a crisper final transcript after save.

  1. Windows: run setx OPENAI_API_KEY "...", then restart Chrome.
  2. Mac: launch Chrome from a shell with OPENAI_API_KEY, or run build-inbox openai:key:set.
  3. Enable it with the Transcript toggle, or run build-inbox transcription:mode openai.

Privacy note: only audio.webm is sent for transcription. Screenshots are not sent.

OpenAI Cleanup

Optional. Cleanup/classification turns the final transcript into a generated task breakdown for Codex.

  1. Enable it with the Cleanup toggle, or run build-inbox cleanup:enable.
  2. It generates brief.generated.md and analysis.generated.json.

Privacy note: no screenshots go to OpenAI for cleanup. Only transcript text plus screenshot markers and filenames are sent.

Codex CLI

Build Inbox saves each capture inside the selected project repo under .build-inbox/inbox/<session-id>/.

That folder contains codex-prompt.md, brief.md, metadata.json, the transcript, audio, and screenshots. The Codex button runs the local codex command from the repo root and passes codex-prompt.md plus screenshots.

  1. Install/sign in to the local Codex CLI. Being signed in here is not always the same as having a codex command available to Chrome.
  2. Add/select the project repo in Build Inbox.
  3. Capture, stop, review the transcript, then press Codex.
  4. If Codex cannot launch, press Save, then run build-inbox codex:run <session-id> from a terminal or use Codex Chat below.

Codex Chat

If you prefer this chat instead of the local CLI, press Save, then tell Codex chat: Please process the Build Inbox capture folder at <repo>/.build-inbox/inbox/<session-id>/ and follow codex-prompt.md.

You can also open codex-prompt.md from the saved capture folder and use it as the prompt.

Attach screenshots manually if the chat cannot read local image files.
